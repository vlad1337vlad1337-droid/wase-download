# Бренд-пресет: wase.chat

Премиальный монохромный минимализм. Ничего лишнего, ни одного цветного акцента.

## Палитра (строго монохром)

- Светлая тема: фон `#E8E8E6` (тёплый серый), поверхность `#FFFFFF`, текст `#161616`, доп. фон `#DEDEDC`
- Тёмная тема: фон `#141414`, поверхность `#1E1E1E`, текст `#F2F2F2`, границы `#2A2A2A`
- Серая шкала: `#C5C5C5 → #A2A2A2 → #969696 → #8B8B8B → #7F7F7F → #737373 → #5C5C5C → #454545`
- КРАСНЫЙ — только для критичных/разрушающих действий. Других цветов НЕТ.

## Типографика

- Единственный шрифт: Inter (400/500/600/700), системный фолбэк
- Иерархия — размером и весом, не цветом

## Форма

- Радиусы малые (углы почти прямые), пилюли 999px — только для мелких контролов
- Тени едва заметные; глубина через границы и слои серого
- Иконки: lucide, один визуальный вес
- НИКАКИХ эмодзи в UI

## Тон

Сдержанный, взрослый, «швейцарский». Пустое пространство — часть дизайна.
