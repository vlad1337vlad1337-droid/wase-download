## Search interpretation and limits

Localized H1, descriptions, guides, links and structured data are present in the static HTML without JavaScript. Pages carry self-canonical and reciprocal HTML hreflang for all 13 languages plus `x-default`. Technical correctness is not a complete editorial or native-language review, and many conversion guides use common explanatory text. A useful, accessible page may still be excluded or ranked poorly by a search engine.

Sitemap inclusion helps discovery but does not guarantee crawling, indexing, ranking or AI citations. [Google's Sitemap guidance](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview) makes this distinction explicit. `noindex` controls indexing; [robots.txt controls crawling](https://developers.google.com/search/docs/crawling-indexing/robots/intro) and is not a replacement. [Yandex recommends HTML hreflang](https://yandex.com/support/webmaster/en/yandex-indexing/locale-pages) for language alternatives and no longer supports language annotations in Sitemap. [Sitemap processing](https://yandex.com/support/webmaster/en/indexing-options/sitemap) is separate from individual-page indexing. Search Console and Yandex Webmaster index-status data were not part of this audit.

The conversion evidence is bounded local ARM64 execution, not certification of all uploaded files or production AMD64 behavior. No production conversion matrix was run. Production remains limited to one conversion at a time, eight queued jobs, 100 MiB input / 200 MiB output, a 180-second total request deadline and its existing aggregate CPU quota.
